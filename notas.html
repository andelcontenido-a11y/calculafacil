¿Cómo se calcula la media de las notas?

Para calcular una media simple se suman todas las notas y se divide el resultado entre el número de notas.

Por ejemplo, si tienes un 6, un 7 y un 8, la media es: (6 + 7 + 8) ÷ 3 = 7.

Esta calculadora permite introducir hasta cinco notas y calcula automáticamente la media entre las notas que hayas rellenado.

Esta calculadora utiliza una media aritmética simple. Si tus asignaturas tienen diferentes porcentajes o créditos, necesitarás utilizar una media ponderada.
